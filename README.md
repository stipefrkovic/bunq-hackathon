# Bunq Hackathon 

**Bunq Hot Spots**

This is the back-end application of _Bunq Hot Spots _created in the 6th edition of the Bunq Hackathon. The main features are authentication, bank payment record matching and RAG/LLM-powered _experience_suggestions.
 
## Setup

1. Create a Python virtual environment, activate it, and install the listed dependencies.
2. With the environment, run `fastapi dev main.py` with the locally hosted URL shown in the shell.

(3. The port on the front-end application could be setup differently and may need to be quickly changed)
